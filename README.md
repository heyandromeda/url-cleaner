# URL Cleaner

A small browser-only utility that removes common tracking parameters without removing legitimate query parameters.

## Use it

Open the public tool: https://url-cleaner.heyandromeda.chatgpt.site

The static app is also available at the repository root. No backend, accounts, analytics, database, or external API is required.

## Test locally

```bash
npm test
python3 -m http.server 8000
```

Then open http://localhost:8000.
